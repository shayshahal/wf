# Show me

Read `../../process/SHOW-ME.md` relative to this skill folder — it is the whole rule set, and it wins over this
file.

Lead with the decision or result. Choose a table, diff, diagram or generated interactive view that
replaces explanation. Keep agreed conditions in the markdown and save HTML views in the round folder.
Use the session's native presentation tools, with the exact files available as fallback. Complete
when the person has been shown the decision, relevant evidence and limits—not merely given a path.
