
## This project (JewelryX)

- A repro or spec red for a reason you cannot see, a 500, a blank screen: run
  `control-jewelryx errors` before guessing. It prints what the stack logged since it last looked:
  failed requests, a 500's traceback, SvelteKit server errors, the browser's console errors. On a
  base without it, the same lines are in `.wf/logs/dev.log`.
